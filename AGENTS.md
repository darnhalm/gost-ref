# Протокол проверки источников и ссылок (обязательный)

Этот файл — правила для любых ИИ-агентов, работающих по этому проекту
(научная работа, диссертация, списки литературы по ГОСТ). Читается на
каждом шаге. Цена ошибки — неверный источник в защищаемой работе.

## 1. Zero-trust к сниппетам поисковика

URL, DOI и идентификатор каталога (РГБ, НЭБ, РИНЦ, Crossref) в сниппете
поисковой выдачи — это НЕ источник, а подсказка, которую надо проверить.
Сниппет часто подсовывает:

- статью **стороннего автора**, который лишь цитирует искомую работу
  (поисковик выдаёт ссылку на цитирующего, а не на цитируемого);
- **устаревший / битый / переформированный** URL (404, редирект, смена
  CMS, блокировка).

**ЗАПРЕЩЕНО копировать URL/DOI/идентификатор из сниппета прямо в ответ.**

## 2. Обязательная проверка перед выдачей ссылки

Прежде чем показать пользователю любой URL или DOI, агент обязан лично
открыть его и сверить содержимое:

1. **Открой страницу браузерным инструментом** (агентский браузер /
   `read_url_content` / встроенный браузер).
   **НЕ через `curl`/`wget`/скрипт с HTTP-запросом.** Научные базы
   (РГБ `search.rsl.ru`, eLibrary, РИНЦ, `protect.gost.ru`,
   `docs.cntd.ru`) блокируют не-браузерные запросы и адреса дата-центров:
   код ответа там ничего не доказывает, живая страница легко отдаёт
   403/timeout на curl. HTTP-статус — ненадёжный критерий для этих
   источников. DOI резолвь через `doi.org`.
2. **Сверь на открывшейся странице:**
   - искомый автор присутствует именно как **автор публикации**, а не как
     случайная цитата в чужом тексте;
   - заглавие на странице **совпадает** с заглавием проверяемого источника.
3. **Проверка не прошла** (не открылось / заблокировано / не тот
   материал): ссылку выдавать ЗАПРЕЩЕНО. Агент обязан прямо сказать:
   «прямой URL не открывается (404 / смена CMS / блокировка)». Затем либо
   найти и **так же проверить** рабочее зеркало (КиберЛенинка, eLibrary),
   либо оформить источник как печатное издание без мёртвого URL.

## 3. Отчёт о проверке

Предлагая ссылку, агент кратко подтверждает факт проверки:
*(проверено: страница открыта, автор и заглавие сверены)*.
Идентификатор без проверки — не идентификатор.
