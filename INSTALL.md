# Установка

У ядра **нет обязательных зависимостей** — только стандартная библиотека Python.
Поэтому после клонирования оно работает сразу, без `pip install`. Установка
нужна лишь для MCP-сервера (`mcp`) и чтения PDF (`pypdf`).

```bash
git clone https://github.com/darnhalm/gost-ref.git ~/gost-ref
cd ~/gost-ref
python3 -m pytest tests/ -q          # должно быть 180 passed
```

Проверка без установки:

```bash
python3 -m gost_ref.cli reformat -s 7.0.100 "Иванов И.И. Заглавие. М., 2020. 100 с."
```

## Полная установка (MCP-сервер и PDF)

```bash
cd ~/gost-ref
pip install -e ".[all]"
gost-ref pair < источник.json
```

Подключение MCP-сервера — в `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "gost-ref": {
      "command": "python3",
      "args": ["/Users/<вы>/gost-ref/server.py"]
    }
  }
}
```

Путь должен быть полным. После правки конфига перезапустите приложение.

## Удалённый сервер (HTTP)

Тот же `server.py` умеет работать по HTTP — для этого он поднимает транспорт
`streamable-http` MCP SDK вместо stdio. Ядро и набор инструментов те же:

```bash
GOST_REF_API_KEY=dev-secret python server.py --transport streamable-http --port 8080
curl -s localhost:8080/health          # {"status":"ok","service":"gost-ref"}
```

Подключение клиента к уже развёрнутому серверу:

```bash
claude mcp add --transport http gost-ref https://<адрес>/mcp \
  --header "Authorization: Bearer <GOST_REF_API_KEY>"
```

Docker, выкладка в Yandex Cloud Serverless Containers, обновление через GitHub
Actions, полный список переменных окружения и что происходит с
`read_pdf_metadata` в удалённом режиме — в `DEPLOY.md`.

## Навык

`skill/SKILL.md` — инструкция для Claude: как определять тип источника, какие
поля обязательны, а какие факультативны, и чего не делать никогда. Сборку строки
она не выполняет — только направляет вызовы к этому пакету.

**В своём аккаунте.** Скопируйте `skill/SKILL.md` в папку навыков (в Claude Code
это `~/.claude/skills/gost-references/SKILL.md`) либо попросите Claude сохранить
навык — он покажет карточку на подтверждение.

**В чужом аккаунте.** Навыки не передаются вместе с репозиторием: каждый аккаунт
сохраняет их у себя. Достаточно дать человеку адрес репозитория и сказать:
«прочитай `skill/SKILL.md` и сохрани как навык». Claude на той стороне прочитает
файл, предложит сохранение, владелец аккаунта подтвердит одним нажатием.

Навык ищет пакет в `~/gost-ref`. Распаковали в другое место — поправьте пути
самонастройки и вызова ядра в установленном SKILL.md. Храните клон вне папки
навыков: вложенный `skill/SKILL.md` иначе может обнаружиться как второй навык.
При использовании читайте также AGENTS.md и references/normative-policy.md
из корня пакета. Обычный запуск не делает git pull; после обновления пакета
отдельно синхронизируйте установленный навык, сохранив локальный путь.

## Где это работает

| Среда | Состояние |
|---|---|
| Claude Code, Cowork | Полностью: есть shell, пакет запускается |
| Обычный чат claude.ai | Без среды выполнения или MCP оформление ядром недоступно; ручная сборка не является запасным режимом навыка |
| MCP-клиенты | Через `server.py`, подключается в каждой среде отдельно |
