# Поиск Academia.edu

Используй инструмент `search_academia`, когда пользователь просит найти текст,
публикацию или автора на Academia.edu.

1. Передай исходный запрос без перевода и без добавления выдуманных терминов.
2. Покажи заглавие и прямую ссылку каждого результата.
3. Всегда называй результаты кандидатами из веб-поиска: наличие ссылки не
   подтверждает автора, издание, библиографические поля или доступность файла.
4. Если результат нужен для цитирования или ГОСТ, сначала открой выбранную
   страницу и сверь заглавие и автора, затем получи недостающие метаданные из
   Crossref, OpenAlex либо из самого документа.
5. Не заявляй, что просмотрел или скачал текст, если была получена только
   поисковая карточка.
6. Не предлагай обход авторизации, платного доступа или технических ограничений.

В плагине нет инструмента скачивания: он возвращает только результаты и ссылки.

## Роль в гибридном режиме

Этот локальный MCP — резерв на случай, когда облачный
`gost-ref.search_academia` вернул `status: "search-pages"`, нуль
кандидатов или ошибку блокировки поисковика. Не вызывай оба
инструмента без необходимости. Локальный процесс не запускается из
облака: пользователь включает его ярлыком на Mac. Без MCP Tunnel этот
инструмент недоступен в обычном веб-чате ChatGPT.
